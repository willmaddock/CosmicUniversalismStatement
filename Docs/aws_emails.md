# AWS Correspondence Regarding CU Initiative Support

**Cosmic Universalism Computational Intelligence Initiative**  
*Date: August 5, 2025*

## Overview

This document presents correspondence between the Cosmic Universalism Computational Intelligence Initiative (CU) and Amazon Web Services (AWS), demonstrating AWS's support through the AWS Educate program, as recommended by AWS Academy Support. Private information has been redacted for confidentiality. The first email from AWS acknowledges the CU Initiative's request for reconsideration of a declined AWS Academy application. The second email confirms the declination but recommends AWS Educate and other programs, supporting the initiative's goals.

**Customer Request Information:**

Dear AWS Academy Team,

I’m writing as the founder and Central Point of Contact (CPOC) of the CU Computational Intelligence Initiative regarding the recent decline of our institution’s application to join the AWS Academy program.

William Maddock

## Email from AWS Academy Support (Response)

- **Date**: July 16, 2025
- **From**: Anjali S., Amazon Web Services, AWS Academy Support
- **To**: William Maddock
- **Subject**: RE:[CASE 175260055100751] [AWS Academy Form Submission] - Institution Application Declined -- Request for Reconsideration

Dear William Maddock,

Thank you for contacting AWS Academy Support.

Please note, CU Computational Intelligence Initiative is not recognized as an accredited, higher education institution awarding transferable academic credentials to learners enrolled in programs of study and therefore does not qualify for membership in AWS Academy.

However, you’re invited to explore other no-cost, cloud education programs including AWS Educate, AWS Skill Builder, AWS Cloud Quest, and/or AWS Skills Centers.

Best regards,  
Anjali S.  
Amazon Web Services

The following statement from the CU Initiative’s documentation further confirms AWS's support:
